# Lab

1. Practice in terminal by exploring common commands.
    - [bash](https://www.educative.io/blog/bash-shell-command-cheat-sheet)
    - [powershell](https://www.powershelltips.com/powershell-cheat-sheet/)
    - Make sure to understand how to create directories and create a basic project structure ( if not already using a project structure )
    - Learn how to navigate directories and "know" which directory you are in
2. Practice creating python environments:
    - Create a new project following a pre-existing structure or the structure created in step 1
    - create a venv of some sort (anaconda, python venv, uv, etc) and install common libs such as pandas.
    - practice creating envs with different versions of python. how does this affect the common libs being installed if at all?
    - write a small hello world script or some other basic functions in the envs.
3. Practice with terminal text editor such as vim or nano:
    - [vimadventures](https://vim-adventures.com/)
    - [vimhero](https://www.vim-hero.com/)
    - `vimtutor` from cli
    - [nano](https://www.cs.umb.edu/~ghoffman/linux/nano_text_editor.html)
    - once you are more comfortable with vim/nano, edit your simple hello_world script from step 2 using vim/nano instead of a code editor
